## 1. 模块与构建边界

- [x] 根 Reactor 包含 Agent、Tool、RAG、AI Capability 四个能力模块。

## 2. 破坏性迁移

- [x] Agent 与 RAG 顶层制品名保持不变。
- [x] Tool 公共契约及实现迁入 `com.fons.cloud.ai.tool`。

## 3. 依赖与按需装配

- [x] Agent Starter 仅跨能力依赖 Tool Common，不传递 Tool Starter。
- [x] RAG Starter 仅跨能力依赖 AI Capability Common，不传递 AI Capability Starter。
- [x] Tool Starter 最小上下文可以独立加载。
- [x] AI Capability Starter 在多模态关闭时不创建图片识别 Bean，开启时按新前缀创建。
- [x] RAG 在无图片识别 Bean 时不创建图片 Reader，其他 Reader 仍可加载。
- [x] RAG 在存在图片识别 Bean 时创建图片 Reader。
- [x] Tool 注册中心和 RAG Reader 门面不再依赖全局静态 `SpringUtil` 获取 Bean。
