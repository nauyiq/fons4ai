# 四能力模块拆分实施报告

> 功能标识：`four-capability-module-split`
> SDD 等级：`S2`
> 实施日期：2026-07-13
> 实施范围：T001-T009

## 1. 实施摘要

本次按 Agent 编排、工具管理、RAG、AI Capability 四个能力完成模块拆分。保留 `fons4ai-agent` 与 `fons4ai-rag` 顶层制品名，新增 `fons4ai-tool` 与 `fons4ai-capability`；四个能力均按 Common 与 Spring AI Starter 分层。旧包名、旧配置前缀和兼容别名均未保留。

配置前缀统一为：

- 工具管理：`sys.tool.tavily`
- RAG：`sys.rag.vector`
- 图像生成：`sys.ai.image-generation`
- 多模态：`sys.ai.multimodal`

## 2. 主要变更

- Tool Common 承载工具分类、元数据、Web 结果模型、Provider/Parser SPI 与注册表契约；Tool Starter 承载 Tavily 和 Spring AI 适配。
- AI Capability Common 承载图像生成、图片识别 Port 与错误码；AI Capability Starter 承载千问图像生成和 Spring AI 多模态适配。
- Agent Starter 仅跨能力依赖 Tool Common，RAG Starter 仅跨能力依赖 AI Capability Common。
- Tavily、图像生成和多模态配置切换到新前缀，旧前缀不提供兼容绑定。
- Tool 与 RAG 注册/门面改为构造器注入，移除对全局 `SpringUtil` 的依赖。
- 修正 Tool 元数据 Provider 标识：按 `ToolProvider.getProviderName()` 登记，确保 Web Search 可以反查 Provider；旧实现把 `inputSchema` 写入 `providerName` 属于与公开契约冲突的潜在缺陷。
- 保留用户工作区已有 Agent 提示词和执行流程改动；仅为全量编译补齐 `PlanExecuteAgent` 已缺失的字段与默认轮次。
