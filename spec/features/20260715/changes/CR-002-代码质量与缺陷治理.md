> 文档状态：正式

## 1. 变更摘要

- 变更一句话说明：在保持现有公共调用、Redisson 任务协调和客户端流协议不变的前提下，精简 Base、ReAct/Web 和 Plan 代码，修复终态、事件并发、工具权限和取消边界缺陷。
- 本次变更结论：采用用户确认的“方案二”，优先处理代码逻辑、重复代码和已确认缺陷，不引入新的 AgentFactory、协调器 SPI、审批平台、配置项或下游协议。
- 是否建议新建 feature：否；本次仍属于共享 Agent 运行内核的质量治理，不替换既有 REQ/AC 或核心调用流程。

## 2. 变更原因

- 用户诉求：以 `BaseAgent` 为起点优先精简代码、提取重复逻辑、删除无效代码并修复潜在 BUG，同时避免本轮演变为新的架构或接入能力建设。
- 业务或技术背景：当前共享 Run 主体结构已完成，但终态清理仍可能被基础设施异常中断，事件发送忽略结果，Web 增强可反向破坏工具成功路径，Plan 类职责过重且存在工具暴露和迟到任务风险。
- 不变更的影响：继续积累超长类和重复 Builder；清理、解析和异步竞态可能在既有测试通过时导致 completion 悬挂、事件丢失或取消后继续产生副作用。
