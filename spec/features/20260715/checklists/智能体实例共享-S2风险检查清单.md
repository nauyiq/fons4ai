# 智能体实例共享 S2 风险检查清单

> 功能标识：`agent-instance-sharing`
> 检查日期：2026-07-15
> 当前结论：自动化实现、Spec Review、Code Review 和用户人工 Gate 均已通过；当前框架任务验收完成

## 1. 公共契约与兼容性

- [x] `Agent`、`AgentRun`、`AgentRunResult` 位于 Common，未暴露 Spring AI/Alibaba 类型。
- [x] `stream(request)` 保持冷流语义，每次订阅创建独立 Run。
- [x] `call(request)` 仅组合 `start(request).completion()`，没有复制执行循环或解析 JSON 拼装结果。
- [x] Reactor 非阻塞线程在创建 Run 前拒绝 `call(request)`。
- [x] 已移除 `AGENT_INSTANCE_ALREADY_USED` 行为和错误码。
- [x] 文本、思考、引用、推荐和停止消息继续使用既有 JSON 类型码/内容。

证据：`AgentContractTest`、`BaseAgentSharedInstanceTest`、`AgentTaskManagerTest`、四类 Agent 的聚焦测试。

## 2. 并发与终态

- [x] BaseAgent 不再保存 conversationId、question、sink、计时、工具集合或最终结果等请求态字段。
- [x] ReAct/Web Search 的消息、轮次和引用进入专属 RunContext。
- [x] Plan-Execute 的 RunnableConfig、最近 Graph 状态、think 标志、引用和 finished 状态进入专属 RunContext。
- [x] Skills 的受控 Registry、激活权限、delegate、流缓冲和原生终态标志每 Run 创建。
- [x] Run 终态使用原子门禁，完成、失败、取消、拒绝均只生成一个结构化结果和一次 Hook。
- [x] 主动停止先发送既有停止消息，再确定 CANCELLED 并取消原生订阅，避免 sink 关闭竞态。
- [x] 同一会话的迟到 handle 无法完成、绑定或取消后续新 Run。

证据：`BaseAgentSharedInstanceTest`、`ReactAgentSharedInstanceTest`、`PlanExecuteAgentGraphTest`、`SkillsReactAgentContractTest`。

## 3. Redis 租约与停止命令

- [x] 任务租约为版本化 JSON：`version/instanceId/runId/agentType`。
- [x] 停止命令为版本化 JSON：`version/conversationId/runId`。
- [x] Redis 释放采用 `compareAndSet(leaseValue, null)`，不再无条件删除。
- [x] 正常完成不 dispose、不发送“用户停止生成”；主动取消才发送停止消息。
- [x] 非法、旧版本或迟到的租约/停止命令被忽略。
- [x] TTL 保持 30 分钟、5 分钟刷新；归属变化时本地旧任务被释放。
- [x] 真实 Redis 多实例联调适用性：本轮不适用。当前交付是框架库/Starter，尚无下游宿主应用和部署拓扑；已由确定性测试验证租约、停止命令和 CAS 契约，真实多实例验证转为下游接入阶段的兼容性建议，不阻塞本轮验收。

迁移说明：当前无业务接入；同版本节点协同升级。旧临时租约等待 30 分钟 TTL 或停机窗口确认后清理。回滚时先停止运行任务，再整体回退 TaskManager 与 Agent 公共契约。

## 4. 技能权限与资源安全

- [x] 技能名、描述、数量、正文大小和工具绑定在受控 Registry 中校验。
- [x] 技能摘要只暴露 `skill://<name>`，不包含物理路径或正文。
- [x] `read_skill` 成功后才产生当前 Run 的激活权限。
- [x] 技能工具执行入口再次校验当前 Run 激活状态。
- [x] 资源工具只在存在激活技能后动态开放，且只能访问已激活技能。
- [x] 文件系统解析器拒绝绝对路径、`..` 和符号链接逃逸，并限制目录、大小和数量。
- [x] 每 Run 固定技能目录快照；reload 只原子发布给后续 Run。
- [x] 共享 Agent 连续运行时激活集合不复用。

证据：`GuardedSkillRegistryTest`、`FileSystemSkillResourceResolverTest`、`SkillsReactAgentContractTest`、`SkillsReactAgentExecutionTest`。
