## 2. 实现确认门禁

- 状态：已获用户确认，T001-T009 已进入实现
- 规划产物不等于实现授权。
- 生成本任务规划文档后必须暂停，等待用户确认后才能进入代码实现。
- 用户确认执行且未指定任务 ID 时，默认执行全部未完成任务。
- 用户指定任务 ID 时，例如 `执行 T001,T002`，只执行指定任务及用户明确允许补齐的必要依赖。
- `看看`、`下一步是什么`、`继续看` 等不明确指令不得视为实现确认。
