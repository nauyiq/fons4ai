## 共存规则

- Spring AI 和 LangChain4j 使用不同泛型 payload 的独立注册表。
- 两个框架共享一份 MinerU HTTP 客户端和中立 provider。
- native 与 MinerU 结果不做往返转换；adapter 只参与 MinerU 路径。
- `DEFAULT` 固定 native；无自动 fallback。

## 待扩展

新增 provider 时应实现公共 `DocumentParseProvider<R>`、声明 `DocumentParserCapability`，并为每个目标框架提供必要的边界适配。是否支持新 provider、框架或默认选择策略必须通过独立设计和验证后再更新矩阵。
