## 1. 项目简介

- 项目定位：Fons4AI 是持续迭代的可插拔 AI Agent 开发框架，以 Spring Boot Starter 形式提供智能体执行引擎、工具编排、RAG 检索增强、多模态识别和图像生成等 AI 能力，供上层业务系统按需接入。
- 核心技术能力：Agent 编排、工具管理、知识检索增强、AI 能力接入。
- 主要使用方：接入 Fons4AI Starter 的上层业务系统。
- 当前知识可信度：项目级结构和当前实现链路来自源码与用户确认；未提供正式配置样例、业务接入样例或测试证据的部分标为待建模。
- 基线确认摘要：按技术框架项目建模；能力域与实现模块分离；Spring AI 为当前适配实现，后续可接入其他框架。

## 5. 高风险技术能力与建模优先级

| 优先级 | 技术能力域 | 原因 | 建议动作 |
| --- | --- | --- | --- |
| P0 | Agent 编排 | 公共执行契约与 Spring AI 类型耦合，直接影响未来多框架适配 | 优先建模 Agent 核心协议与适配边界 |
| P0 | 工具管理 | 当前实现放在 Agent 模块，MCP 与工具结果解析需定义独立边界 | 优先建模工具 SPI、回调与治理边界 |
| P1 | 知识检索增强 | 文档读取、Embedding 与 PgVector 资源耦合，需要明确可替换接口 | 建模知识入库和检索链路 |
| P1 | AI 能力接入 | 图像生成和多模态实现分散，且存在供应商实现限制 | 建模统一能力契约与提供商适配 |
