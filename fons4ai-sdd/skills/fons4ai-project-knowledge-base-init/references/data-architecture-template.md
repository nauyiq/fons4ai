## 10. 验收检查

- [ ] 每个核心数据对象能追溯到来源证据。
- [ ] 每个 SQL 文件只描述一个数据库/服务内的内聚业务模型。
- [ ] 每个 SQL 文件都有明确 DDL 来源：数据库 MCP 查询或仓库 SQL 文件。
- [ ] 未配置 MCP 且仓库无 SQL DDL 时，已在数据架构中标记 `待确认`，未从实体类、Mapper 或 ORM 注解推断生成 DDL。
